# Реестр библиотек

В отличие от адаптеров, библиотека живёт прямо здесь: вход —
`<имя>.saltic`, код — папка `<имя>/`, паспорт — `<имя>.passport.json`, строка
— в `libraries.txt`. Папка самостоятельна — потом уедет в свой репозиторий,
отдельно от реестра адаптеров (`registry/adapters/`). Сверки (`just registry`
для библиотек) ещё нет.

| библиотека | что это |
|---|---|
| `uiengine` | UIEngine: атомы JTML, раскладка, рисование и закрытая библиотека жителей по уровням — движок и библиотека одно (решение автора 16.11.2026) |
| `bignum` | большие целые со знаком: длинная арифметика, деление с остатком, степени; проверки — `checks/` |
| `ieee754` | float32 и float64 по стандарту IEEE 754 программно, бит в бит; стоит на `bignum`; проверки — `checks/` |
| `exponent` | степени и логарифмы на дробных: exp, log, log2, log10, x^y; проверки — `checks/` |
| `vector` | векторы в 3D: сумма, разность, скалярное и векторное произведение, длина, единичный, точка луча; проверки — `checks/` |
| `rotation` | повороты в 3D кватернионами: ось и угол, сложение, вектор, матрица, slerp; проверки — `checks/` |
| `linear` | разложения матриц на `core.matrix`: LU (определитель, системы, обратная), QR, SVD; проверки — `checks/` |
| `signal` | сигналы: FFT и ДПФ, свёртка, КИХ-фильтр, биквад низких и высоких частот; проверки — `checks/` |
| `statistics` | среднее, дисперсия (Уэлфорд), медиана, квантили, корреляция, регрессия; проверки — `checks/` |
| `random` | генератор xoshiro128**, равномерное, нормальное, экспоненциальное, Пуассон, перемешивание; проверки — `checks/` |
| `sha256` | хеш SHA-256 и HMAC-SHA256; проверки — `checks/` |
| `sha512` | хеш SHA-512 на парах 32-битных половинок; проверки — `checks/` |
| `chacha` | шифр ChaCha20, подпись Poly1305, шифр с подписью RFC 8439; судья — OpenSSL; проверки — `checks/` |
| `x25519` | обмен ключами X25519 (RFC 7748), поле 2^255 − 19 — жилец `field`; судья — OpenSSL; не за постоянное время; проверки — `checks/` |
| `ed25519` | подпись Ed25519 (RFC 8032) на поле `x25519` и `sha512`; судья — OpenSSL; не за постоянное время; проверки — `checks/` |

## Паспорт

`<имя>.passport.json`, ключи — английские, как у адаптеров, без железных
(`identifiers`, `hardware`, `protocols`, `primitives`, `effects`): `title`,
`saltic_version` (в составе какого Saltic), `own_version` (растёт при правке
кода), `author`, `role` (`library`), `purpose`, `depends_on`,
`architectures`, `state`, `log`. Поля решены с первой библиотекой —
`uiengine` (16.11.2026), ключи на английском — 17.11.2026.

Ядро языка (`soul/seed`) — не библиотеки и сюда не выносится. Кандидаты —
`soul/craft` (протоколы и форматы) и инструменты.
